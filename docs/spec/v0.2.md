# Dumpling v0.2: product spec

The first public release of the app, under a new name. A stranger with no paid key goes from the download to daily use, and keeps using it without Obsidian. Written on 2026-10-27 after a grilling session with the maintainer. It builds on [`shareable.md`](shareable.md); where this spec is silent, its rules hold. Vocabulary is from [`CONTEXT.md`](../../CONTEXT.md).

## 1. Decisions

- **Audience: strangers, after the maintainer.** The maintainer uses v0.2 daily for two weeks before the release. There are no test users before the release; strangers report problems after it.
- **The release waits for all of v0.2.** No v0.1.0 is published. Issue adib-11/second-brain#65 (S11) is replaced by the release slice in §9, without its stranger test.
- **The name is Dumpling**, after the Dump. "Second brain" stays the description: "Dumpling: a second brain on your computer". The rename covers the repo, the app id, the settings folder and the default folder (§7).
- **The Free Engine is the default.** It needs no key and no account. The Owner can choose a Key Engine instead.
- **Only zero-retention free models.** The app offers a free model only while its terms say it keeps no data and does not train on it.
- **Key Engines: OpenAI, Gemini, Anthropic and OpenRouter.** Gemini is a paid key like the others. There is no Gemini free-tier path: its free tier trains on the data, people may read it, and it is not allowed for users in the EEA, Switzerland or the UK.
- **Telegram is optional.** First run is folder, then Engine. The phone is the next step, not a gate.
- **A main window, built around Today.** The app stays in the menu bar (the tray on Windows and Linux). Its window has a Dock or taskbar icon while it is open. The setup window goes away.
- **Pages are read-only in the app.** The Owner edits Pages in Obsidian or any editor. The app edits only Dumps that wait in the Inbox.
- **Quick capture on the computer.** A global shortcut opens a box that makes a Dump from text, a link or an image.
- **Report a problem** opens a pre-filled GitHub issue with no Dump or Page text in it.
- **Issues and the spec live in the public app repo.**

## 2. What a Dump can be

| Dump | Free Engine | Key Engine |
| --- | --- | --- |
| Text (Telegram or quick capture) | Filed | Filed |
| Image (Telegram photo, or pasted or dropped into quick capture) | Saved as a JPEG about 1200 px wide; its text is read by the free model | Same, read by the Key Engine |
| Link | Fetched into a `<name>.fetched.md` sidecar as today (shareable §5): full article text, YouTube captions (auto-generated too), PDFs, X, LinkedIn, Apple Podcasts transcripts, Instagram and TikTok captions | Same |
| Voice note | A placeholder Dump that says a key is needed; the audio is kept until then | Transcribed when the provider takes audio (OpenAI, Gemini); otherwise as Free |
| Any other file | A placeholder Dump, not downloaded | Same |

A video or podcast with no published transcript stays unfetched; nothing transcribes audio from a link in v0.2.

`/ask` and the Ask tab answer Recall and Persona questions from the Pages, as today.

## 3. Engine

**Free Engine.** The bundled opencode runs a free model from its `opencode` provider with no credentials. Today two models qualify:

| Model id | Terms (opencode.ai/docs/zen, 2026-10-27) | Images | Audio |
| --- | --- | --- | --- |
| `opencode/glm-5.3-flash-free` | Zero retention, no training | Yes | No |
| `opencode/deepseek-v4.1-flash-free` | Zero retention, no training | Yes | No |

- The default is the one that does better on the v1 fixture set with `check-ingest` (`tests/fixtures/ingest`). The other is the fallback.
- The list of allowed free models is one constant in the code. A model leaves the list when its terms change.
- Free models are "free for a limited time", with no published limits. When the default fails with a `429 FreeUsageLimitError`, or the model is gone, the app tries the fallback once. If that fails too, the Dumps stay in the Inbox, the run fails as today, and the notification offers "Add a key". The app never falls back to a model that keeps or trains on data.
- The app reads photo text through the same opencode run, with the image attached, so a Free install needs no direct API call.

**Key Engine.** The Owner picks a provider and pastes a key. The app checks the key with one cheap call to that provider, stores it in the OS keychain as today, and passes it to opencode in the environment, never in arguments. Each provider has a default model and a cost table, so `.state/runs.tsv` keeps a cost per run. A provider is offered only after its default model passes the fixture set.

**What leaves the computer.** The Engine step says where the Dumps go: to opencode's servers in the US and EU for the Free Engine, or to the chosen provider for a Key Engine. The current line that OpenAI does not train on API data appears only for OpenAI.

## 4. First run

1. Choose a folder (default `Documents/Dumpling`).
2. Choose the Engine: **Start free** (selected) or **Use my own key**.
3. Done. The Owner lands on Today.

Today shows a **Connect your phone** card until a bot is connected. It runs the current bot steps (BotFather, token, `/start`). Until then, `/ask` in Telegram and Follow-ups are off, and capture is by quick capture only.

## 5. Main window

Five tabs, and no more:

- **Today.** Dumps captured and filed today, failures with a Retry, Follow-ups waiting for an answer, Open threads, and one stats strip: Dumps this week, Engine cost this month, Pages, last Ingest. The numbers come from `.state/runs.tsv`, `vault/wiki/log.md` and the files.
- **Inbox.** The Dumps waiting for the next Ingest. The Owner can edit or delete one before it is filed.
- **Pages.** Read-only markdown with `[[wiki links]]` that open the Page, and a list of the Pages that link here. Search scans the files; at thousands of Pages it moves to an index. "Open in Obsidian" shows only when Obsidian is installed. No graph view.
- **Ask.** The current Ask box.
- **Settings.** Engine and key, bot, folder, backup remote, quick capture shortcut, open at login.

The menu bar menu keeps Ingest now, Undo last Ingest and Quit, and gains Open Dumpling.

The window is React with Vite, in the existing Electron app.

## 6. Quick capture

- The shortcut is ⌃⌥Space on Mac and Ctrl+Alt+Space on Windows and Linux. If the system refuses it, Settings says so and asks for another.
- The box takes text, a link, or an image pasted or dropped on it. Enter saves it as a Dump in the Inbox with `device: desktop`, and the box closes.
- Each Dump is a commit, as a Telegram drain is.
- It makes plain Dumps only. An Addendum from the computer is out of v0.2.

## 7. Rename

- The repo `adib-11/second-brain-app` becomes `adib-11/dumpling`. GitHub keeps the redirect, and the update check uses the new name.
- The app id, product name, executable name, settings folder and default folder all use Dumpling.
- On first start, the app moves an existing install's settings, key and token to the new settings folder. It does not move the second brain folder; it keeps using the folder it has.

## 8. Look and feel

- A logo, drafted by image generation, then redrawn as a vector.
- An app icon in every size each system needs (`.icns`, `.ico`, PNG).
- A menu bar icon in one colour, so macOS can tint it, plus the failing and not-drained variants.
- One set of colour and type tokens, used by every window, with dark mode.
- Keyboard use and screen readers work in every window.

## 9. Slices, in order

1. **Engine** (§3). Free models, the four Key Engines, the fixture runs that pick the default, the fallback.
2. **Rename** (§7). Can run beside 1.
3. **Main window** (§4, §5). After 2.
4. **Quick capture** (§6). After 3.
5. **Look and feel** (§8). Beside 3 and 4, once the name is set.
6. **Report a problem.** A menu item and an issue template. The issue has the app version, the system and the last Ingest error, and no Dump or Page text.
7. **Release.** Screenshots of Open Anyway and SmartScreen, a trademark search for Dumpling, two weeks of daily use by the maintainer, the monthly cost against shareable §2, then the published release.
